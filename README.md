# GemStalker

Pre-migration Solana bonding curve scanner.

## Features

- pump.fun websocket tracking
- bonding curve monitoring
- early gem alerts
- Telegram premium alerts
- buy/sell pressure
- alpha score
- inline buttons

## Environment Variables

- TELEGRAM_BOT_TOKEN
- CHAT_ID
- HELIUS_API_KEY

## Deploy

```bash
pip install -r requirements.txt
python main.py
```
